# Miles & Memories 🏍️

Miles & Memories is a bike touring website designed around the experience of discovering scenic routes and exploring new destinations on two wheels.

## 🌐 Live Demo

[Visit Miles & Memories](https://miles-and-memories-tour.netlify.app)

## About the Project

This project focuses on presenting a travel-oriented website with visual elements and a layout inspired by motorcycle touring and road-trip adventures.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Deployment

The website is deployed using Netlify.
